What does this word mean here?

Double-click a word on any web page. Contextual Dictionary shows its meanings from the English Wiktionary and lists the one that fits the sentence first. The dictionary and the model that orders it both run on your computer.

Add to ChromeSee what it changes

Free and open source. No account. For Chrome 124 or later, on a computer.

See it work

Three lookups on the practice page, recorded in Chrome as they happened. Under 40 seconds, no sound.

The same dictionary, in a better order

A dictionary lists a word’s meanings in one fixed order, whatever you are reading. The one you need can be the fourth, or the tenth.

Contextual Dictionary keeps every meaning and moves the best fit to the top. On the right is the first meaning each order gives.

A dictionary and a small model, both on your computer

Nothing is generated. The meanings are Wiktionary’s own words; the model only decides which comes first.

Read the user guide

  1. You double-click a word

    Or select up to four words. The extension reads the selection and up to 120 characters on each side of it, and nothing else on the page.

  2. The dictionary answers

    A 66.5 MB copy of the English Wiktionary on your disk, with 1.2 million headwords. The card opens in about a hundredth of a second.

  3. The model orders the meanings

    A 189 MB model made for telling word senses apart, fine-tuned on Wiktionary’s own examples, scores each meaning against the sentence. If it has no answer within three quarters of a second, you get the dictionary’s order.

What you read stays with you

  • The words you select and the pages you read are never sent anywhere.
  • No account, no analytics, no error reports, no remote code.
  • The only network use is two downloads from this project’s GitHub releases, each started by you. After that it works offline.
  • The code is open, so all of this can be checked. Privacy in detail

Install it

It installs from the Chrome Web Store in three steps, and downloads its dictionary and its model once.

  • Chrome 124 or later, on a computer
  • 274 MB of disk for both downloads
  • Free, MIT licence

  1. Add it to Chrome

    Open Contextual Dictionary in the Chrome Web Store and click Add to Chrome.

    Open the Chrome Web Store

  2. Confirm the two downloads

    Open the extension from the toolbar. The dictionary (66.5 MB) gives you definitions; the context model (189 MB) orders them. Each starts only when you confirm it.

  3. Double-click a word

    Any ordinary web page will do, including this one. The practice page has the passages shown above.

Where does it not work?

On Chrome’s own pages, the Chrome Web Store, Chrome’s built-in PDF viewer and inside text fields. A double-click on a link follows the link, as in any browser.

Can I use it without the model?

Yes. With only the dictionary installed, or with “Order by context” switched off, the card shows the dictionary’s order and uses no extra memory.

How fast is it?

On a desktop computer, half the cards are ordered within 0.3 seconds and none waits longer than 0.75. On a slower machine about 70% are ordered in time; the rest show the dictionary’s order, and looking the word up again shows the model’s.

How do I update or remove it?

Chrome updates it by itself and keeps your settings and the dictionary. When an update brings a new context model, as version 0.4.0 does, the extension’s window asks you to confirm that download again; until you do, cards keep the dictionary order. To remove it, use Remove for each download in the extension’s window, then remove the extension in chrome://extensions.

Can I install it without the Chrome Web Store?

Yes. Every release has a ZIP file that Chrome loads as an unpacked extension; the guide has the steps. Chrome does not update that copy, and it keeps its own downloads and settings, apart from the store’s.
