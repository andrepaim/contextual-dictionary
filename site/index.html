Installation

Start reading
with context.

For desktop Chrome 124 or later.

Get the GitHub release
  1. Download and unzip the extension. Choose the Contextual Dictionary extension ZIP under the release’s Assets. Extract it into a folder you’ll keep.
  2. Load the folder in Chrome. Open chrome://extensions, enable Developer mode, and choose Load unpacked. Select the folder containing manifest.json.
  3. Choose your downloads. Open the extension from the toolbar. The 66.5 MB dictionary enables definitions. Add the 147 MB model for contextual ordering.
Updating an existing install?

Extract the new release into the same folder, replacing the existing files. In chrome://extensions, click Reload on Contextual Dictionary, then refresh open tabs. Keeping the same folder preserves your downloads and settings.

How much memory does the model use?

In our desktop tests the model used about 1 GB of additional memory while loaded. It unloads after ten idle minutes. You can use dictionary order on its own.

Where does it work?

Double-click an English word or select up to four words on an ordinary web page. Chrome’s internal pages, the Web Store, the built-in PDF viewer, and text fields are excluded. Press Escape to dismiss the card.
